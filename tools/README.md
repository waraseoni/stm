# tools/ (gitignored)

Portable toolchains yahan rakho, PATH me sirf zaroori add karo.

```
tools/
├─ sdcc/                 # sdcc.exe, sdcc-*.exe, include/, lib/
├─ stm8flash/            # stm8flash.exe + libusb dll
├─ arm-gnu-toolchain/    # arm-none-eabi-*
├─ openocd/
└─ STM32CubeProgrammer/
```

Is folder ka `git status` me na aana `.gitignore` me handle hai. Machine badalne
par `docs/00-setup-windows.md` follow karke dobara download kar lena.
